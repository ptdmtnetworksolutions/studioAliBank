# **App Name**: FinWave

## Core Features:

- Dashboard Overview: Displays the user's total balance, savings account details, and active deposit summaries in a clear, concise format.
- Transaction History: Provides a comprehensive list of all past financial transactions, including incoming funds, outgoing transfers, and deposit activities.
- Fund Transfer: Enables users to securely transfer funds to registered beneficiaries or new recipients within the same bank or to other banks.
- E-Wallet Integration Display: Shows linked e-wallets and their current balances, with options to connect new e-wallets or view details.
- Deposit Management: Allows users to view details of their existing deposits and provides functionality to explore or initiate new deposit products.
- AI Financial Assistant Tool: An AI tool that provides personalized budgeting insights, expenditure summaries, and tailored recommendations for financial products or savings strategies based on transaction history.
- Quick Services Menu: Offers quick access icons for frequently used services like top-ups, bill payments, and QR code payments.

## Style Guidelines:

- Primary color: Rich Gold (#B8860B) for energetic calls to action and important elements, conveying a sense of premium and trust.
- Background color: Soft Beige (#F5F5DC), a subtle and warm hue providing a clean and elegant canvas that aligns with the brown-gold theme.
- Accent color: Deep Brown (#4A2C00), offering a sophisticated contrast and used for subtle highlights, secondary interactive elements, or text that requires a slight emphasis.
- All text: 'Inter' (sans-serif), chosen for its objective, neutral, and highly readable characteristics, making it suitable for both headlines and detailed banking information.
- Utilize simple, clean line-based icons for all interactive services to maintain clarity and a modern aesthetic.
- Implement a mobile-first responsive layout with clearly defined sections, generous spacing, and a hierarchical structure to enhance user experience, especially on smaller screens.
- Subtle and fluid animations for page transitions, data loading indicators, and interactive element feedback to create a smooth and intuitive user interface.
- Incorporate 'Liquid Glass' UI elements, characterized by frosted, translucent backgrounds and subtle refractive effects, to create depth and a modern, premium feel.
